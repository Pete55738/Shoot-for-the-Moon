# Shoot for the Moon

**The one lever: press LAUNCH.** The rocket flies as high as its parts allow,
earns money for the altitude, and comes back under a parachute. While the crew
turns it around, buy better parts. Ten tiers each of engine, tank,
aerodynamics and hull get a rocket to the Moon; then every Moon flight delivers
a base module until the base is complete.

A simple game for people to waste time on and get their dopamine hits. One HTML
file, no build step, no accounts, no downloads.

- **Play:** https://shoot-for-the-moon-9834.netlify.app
- **App:** `app/shoot-for-the-moon.html`
- **How it is built:** `CLAUDE.md`, `docs/ARCHITECTURE.md`, `docs/PRD-shoot-for-the-moon.md`
- **Balance sim:** `node scripts/sim.mjs --curve`
- **Critic camera:** `node scripts/shot.mjs --all`
